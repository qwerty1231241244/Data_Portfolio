
# Projects Portfolio

This repository contains mini projects demonstrating **web scraping with Playwright**, **data processing with Pandas**, and **Excel automation**. These projects showcase automation, data cleaning, and analysis skills suitable for freelance work.

---

## 1️⃣ Web Scraping Project

**Description:**  
Scrapes book data from an e-commerce website, navigates multiple pages automatically, calculates discounted prices, and exports results to Excel.

**Technologies Used:** Python, Playwright, Pandas, Excel

**Features:**  
- Multi-page scraping automation  
- Data extraction and cleaning  
- Discount calculation  
- Excel report generation

**Output File:** `books_scraping.xlsx`

**Use Case:**  
- E-commerce price tracking  
- Competitor analysis  
- Automated reporting  

---

## 2️⃣ Excel Cleaning Project

**Description:**  
Cleans messy Excel datasets by removing empty rows and duplicates, calculates discounted prices, and exports the cleaned data.

**Technologies Used:** Python, Pandas, Excel

**Features:**  
- Removes empty rows and duplicates  
- Adds calculated columns  
- Excel report generation

**Output File:** `excel_cleaning.xlsx`

**Use Case:**  
- Preparing datasets for analysis  
- Automating data cleanup  
- Reporting for small businesses  

---

## 3️⃣ Excel Data Analysis Project

**Description:**  
Processes product data, calculates discounted prices, labels products, flags expensive items, sorts by price, and exports to Excel.

**Technologies Used:** Python, Pandas, Excel

**Features:**  
- Discount calculations  
- Product labeling  
- Flagging expensive items  
- Sorting and Excel export

**Output File:** `products.xlsx`

**Use Case:**  
- Business analytics  
- Automated reporting  
- Data insights for decision making
